# Jamesy-tech/toolbox
This repository contains a variety of Bash and other command-line scripts for any use. Feel free to do whatever you want with them!

## Installation

First, make sure you have Git installed.

### Install Git

**Ubuntu/Debian:**
```bash
sudo apt install git
```

**macOS:**
```bash
brew install git
```

**Windows:**
Download Git from [git-scm.com](https://git-scm.com/).

### Clone the repository

Once Git is installed, clone the toolbox:

```bash
git clone https://github.com/Jamesy-tech/toolbox.git
cd toolbox
```
